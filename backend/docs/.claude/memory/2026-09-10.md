## 5. 冒烟测试脚本（test-smoke.js）
- 新增项目根目录 `test-smoke.js`（ESM + Node 内置 `fetch`），聚焦**业务逻辑正确性**；内网活动、无密码登录，故不覆盖暴力破解/限流/XSS/CSRF 等安全项。
- 共 6 组 19 步：
  - 完整流程：学生登录 → 浏览 5 摊解锁 knowitall → 查奖励 → 取码 → 工作人员登录 → 核销 → 复查已核销。
  - 幂等性：重复浏览 `uniqueBoothCount` 不变；重复取码返回同一码；重复核销 → 409 `CLAIM_TOKEN_REDEEMED`。
  - 权限：学生 token 调 `/api/staff/claim-tokens/redeem` → 403 `STAFF_REQUIRED`；无 token 调 `/api/me/reward` → 401 `AUTH_REQUIRED`。
  - 并发：`Promise.all` 两次核销同一码，恰一个成功（200）一个拒绝（409）。
  - 过期：临时把 `events.end_at` 改为 `now-60s`，取码 → 409 `EVENT_NOT_ACTIVE`、核销 → 409 `CLAIM_TOKEN_EXPIRED`，随后恢复原值。
  - 边界：`deviceId=bad-id` → 400 `INVALID_REQUEST`；`eventId=-5` → 400 `INVALID_REQUEST`。
- 每步打印 ✅/❌ 并附关键数据（计数/码值/状态码）；失败不中断，末尾打印 `总结：通过 X/19 步`。
